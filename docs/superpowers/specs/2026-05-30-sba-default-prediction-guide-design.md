# SBA 부실예측 모델 가이드 + EDA 설계 문서

- **작성일:** 2026-05-30
- **데이터:** `SBAnational.csv` (899,164행 / 약 179MB)
- **환경:** Python 3.13, pandas 2.3, scikit-learn 1.7, LightGBM, matplotlib/seaborn, Jupyter
- **이번 산출물 범위:** (1) 진행 가이드 문서(본 문서), (2) EDA 노트북 실제 수행. 본격 모델 학습은 다음 단계.

---

## 1. 목표

SBA 대출 데이터로 **부실(CHGOFF) 여부를 예측하는 분류 모델**의 설계·진행 방법론을
가이드로 정리하고, 그 근거가 되는 **EDA를 실제로 수행**한다.

정형 데이터 + 비정형 데이터(사업체명 텍스트)를 결합했을 때 부실예측 성능이
개선되는지를 핵심 실험으로 둔다.

---

## 2. 예측 시점 (Prediction Point) — 프로젝트의 기준점

> **본 연구는 대출 승인 시점(approval point)에서의 부실 예측을 목표로 하며,
> 승인 이후에만 관측 가능한 정보는 피처에서 제외한다.**

이 한 줄이 피처 집합과 누수 판단의 기준이다.

- **사용 가능(승인시점 정보):** 금액 승인액, 만기, 직원수, 신규/기존, 프랜차이즈,
  지역, 업종, 은행, 승인연도 등
- **제외(승인 이후 관측):** `DisbursementDate`, `DisbursementGross`, `BalanceGross`,
  `ChgOffDate`, `ChgOffPrinGr`

## 3. 타깃 정의

- `MIS_Status` → **`CHGOFF` = 1 (부실)**, **`P I F` = 0 (정상)**

  → 평가지표와 학습 가중치에서 불균형을 명시적으로 고려

## 4. 씬파일러(Thin Filer) 정의 — Proxy 한계 명시

본 데이터셋에는 신용점수·신용이력 컬럼이 없다. 따라서 thin filer를 직접 식별할 수 없다.

> **직접적인 신용이력 데이터가 없으므로, 사업 운영 이력이 짧을 가능성이 높은
> 신규사업자(`NewExist = 2`)를 thin-file proxy segment로 활용한다.**
> thin filer(신용이력 부족자)와 신규사업자(운영이력 부족자)는 유사하나 동일하지 않으며,
> 어디까지나 proxy임을 보고서에 명확히 제한한다.

**적용 방식:** 모델은 전체 데이터로 학습하고, `NewExist = 2` 세그먼트의 성능을
전체 대비 **별도 리포팅**한다. (씬파일러는 결과 해석 관점)

### NewExist 의미 검증 (필수)
- 공식 SBA 정의: `1 = Existing business`, `2 = New business`
- 분포: 기존(1) 644,869 / 신규(2) 253,125(약 28%) / 이상치(0) 1,034 / 결측 136
- **EDA 1단계에서 value_counts와 공식 정의를 대조 검증**하고, 이상치 `0`은
  결측 처리한다. (해석 오류 시 EDA·세그먼트·보고서 전체가 틀어지므로 반드시 확인)

## 5. 피처 설계 (정형 + 비정형)

### 5.1 정형 피처
- **금액계:** `GrAppv`, `SBA_Appv` (문자열 `$`,`,`,공백 제거 → float)
  - 파생: **SBA 보증비율** = `SBA_Appv / GrAppv`
- **조건계:** `Term`, `NoEmp`, `CreateJob`, `RetainedJob`, `NewExist`,
  `FranchiseCode`(→ 프랜차이즈 여부 이진), `UrbanRural`, `RevLineCr`, `LowDoc`
- **범주계:** `State`, `BankState`, `NAICS 상위 2자리(업종 대분류)`, `ApprovalFY`

### 5.2 비정형 피처
- **주축:** 사업체명 `Name` → TF-IDF 임베딩
  - **character n-gram (3~5)**, `min_df` 설정, `max_features ≈ 5000`
  - 근거: "MOTEL", "TRUCKING", "NAIL", "LIQUOR", 프랜차이즈 체인명 등이
    업종·안정성 신호를 줄 수 있는 **해석 가능한 비정형 신호**
  - **누수 주의:** "BANKRUPTCY", "RECOVERY" 등 미래 결과를 암시하는 단어와,
    지나치게 희귀한 이름의 memorization을 경계 (`min_df`, `max_features`로 억제)
  - BERT 등 대형 임베딩은 복잡도 급증·설명력 감소로 **이번 범위 제외**(향후 옵션)
- **보조:** NAICS 2자리 → 업종 텍스트 라벨

### 5.3 핵심 실험
**"정형만" vs "정형 + Name TF-IDF"** 성능 비교로 비정형 피처의 기여도를 정량 입증.

### 5.4 누수(Leakage) 점검
- 승인 이후 관측 컬럼(2장) 전부 제외
- `Name` 텍스트의 미래암시 단어 점검
- EDA에서 누수 후보 컬럼을 명시적으로 확인하는 단계 포함

## 6. 범주형 인코딩 전략

- **저카디널리티**(`State`, `UrbanRural`, `NewExist`, `LowDoc` 등)
  → One-Hot 또는 LightGBM native categorical

## 8. 검증·평가

### 8.1 시간 기반 분할 (Time Split) — EDA 반영 확정
random split은 금융에서 비현실적 → `ApprovalFY` 기준 시간 분할.

**우측 절단(censoring) 보정:** EDA 결과 2011년 이후 대출은 만기 미도래로 부실이
과소 집계되고(2013년 2.9%·2,455건, 2014년 1.9%·268건) 표본도 매우 적다.
따라서 **2011년 이후 절단연도는 제외**한다.

- **제외:** `ApprovalFY >= 2011`
- **train:** `ApprovalFY <= 2006`
- **valid:** `ApprovalFY == 2007` (하이퍼파라미터·임계값 튜닝)
- **test:** `2008 <= ApprovalFY <= 2010` (최종 평가, 1회)

(주의: 2006~2008 금융위기 코호트는 부실률 35~43%로 train/test 간 분포 변동이 큼 →
시간 일반화 성능을 보수적으로 평가하게 됨)

### 8.2 평가지표
> **불균형 데이터 특성상 ROC-AUC가 과대평가될 수 있으므로 PR-AUC를 핵심 지표로 사용한다.**
- 핵심: **PR-AUC** (Precision-Recall Curve 강조)
- 보조: ROC-AUC, Recall(부실), Precision, F1
- **전체 vs 신규사업자(thin-file proxy) 세그먼트 성능 비교표**
- **"정형만 vs 정형+Name" 비교표**

## 9. EDA 노트북 구성 (이번에 실제 수행)

1. **로딩·타입 정리** — 금액 문자열 파싱(`$`,`,` 제거), 날짜 파싱, dtype 정리
2. **NewExist 의미 검증** — value_counts ↔ 공식 정의 대조, 이상치 `0` 처리
3. **결측·이상치 점검** — 컬럼별 결측률, 금액/Term 이상치
4. **타깃 분포 및 불균형** — CHGOFF 비율, 결측 타깃 제외
5. **정형 피처별 부실률 관계** — 업종(NAICS2)·주(State)·Term·승인액·NewExist 등
6. **신규사업자(thin-file proxy) 세그먼트 vs 전체 비교**
7. **`Name` 텍스트 탐색** — 길이 분포, 빈출 토큰, 프랜차이즈/체인 패턴, 미래암시 단어 점검
8. **누수 후보 컬럼 점검** — 승인 이후 관측 컬럼 확인
9. **EDA 요약 & 모델링 시사점** — 피처 후보 확정, split 연도 경계 제안
